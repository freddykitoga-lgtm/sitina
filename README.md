# SITINA - Système de Gestion pour ONG

## 📖 Description
SITINA est un système de gestion web développé pour l'ONG SITINA, dédié à l'alphabétisation et l'autonomisation des femmes et enfants vulnérables.

## 🚀 Fonctionnalités
- 📊 Dashboard avec statistiques et graphiques
- 👤 Gestion des bénéficiaires (CRUD complet)
- 📚 Gestion des sessions de formation
- 📝 Gestion des inscriptions et tests
- ✅ Pointage des présences quotidiennes
- 💰 Suivi des micro-projets
- 📈 Rapports et analyses
- 👥 Gestion des utilisateurs (rôles)

## 🛠️ Technologies utilisées
- PHP 8.1+
- MySQL 5.7+
- Bootstrap 5
- Chart.js
- JavaScript vanilla

## 📁 Installation
1. Cloner le dépôt
2. Importer la base de données (`bd_sitina`)
3. Configurer `config/database.php`
4. Lancer le serveur local
